# 记忆引擎：三层记忆 + 跨会话检索

## 记忆架构

```
┌─────────────────────────────────────────┐
│           三层记忆系统                    │
│                                         │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐ │
│  │ 会话记忆 │  │ 项目记忆 │  │ 经验记忆 │ │
│  │ (当前)  │  │ (跨会话) │  │ (跨项目) │ │
│  │ JSONL   │  │ MD      │  │ JSONL   │ │
│  └─────────┘  └─────────┘  └─────────┘ │
│       ↓            ↓            ↓       │
│     读/写        读/写        读/写      │
│      ↑              ↑            ↑      │
│      └──── 检索引擎（关键词+主题） ────┘  │
└─────────────────────────────────────────┘
```

## 会话记忆（session/）

### 写入时机
- 用户提出需求时：写入 user_request
- 总裁完成拆解时：写入 task_breakdown
- 每个 Worker 完成时：写入 worker_outputs
- 每个 Verifier 完成时：写入 verifier_results
- 任务交付时：写入 final_delivery

### 读取时机
- 用户追问时：回溯会话记忆回答
- 新任务开始时：检查是否有未完成的前序任务

### 文件命名
`session-{session_id}.jsonl`，一个会话一个文件

## 项目记忆（project_memory.md）

### 写入时机
- 任务完成后：更新经验教训
- 新增约定时：更新工程约定
- 角色调整时：更新角色映射

### 读取时机
- 每个新任务开始时：总裁先读取项目记忆
- Worker 派发时：将相关约定作为上下文传入

### 内容结构
```markdown
# 项目记忆

## 项目规则
- [跨会话不变的规则]

## 工程约定
- [命名、目录、代码风格]

## 角色映射
- [角色 → 动物 → 职责]

## 验证策略
- [默认级别、特殊规则]

## 经验教训
- [踩坑记录]
- [最佳实践]
```

## 经验记忆（experience/）

### 写入时机
- 任务完成后，总裁提炼经验：
  - 什么做法效果好 → 最佳实践
  - 什么做法不工作 → 踩坑教训
  - 哪个角色适合什么 → 角色适配

### 写入格式（experience.jsonl）
```json
{"id":"exp-001","timestamp":"...","topic":"security","type":"lesson","content":"emoji字段必须转义，否则XSS","source":"demo-001"}
{"id":"exp-002","timestamp":"...","topic":"parallel","type":"best_practice","content":"测试和文档可并行，都只依赖开发产出","source":"demo-001"}
```

### 主题索引（topics.md）
```markdown
# 经验记忆主题索引

## security
- exp-001: emoji字段必须转义

## parallel
- exp-002: 测试和文档可并行

## roles
- exp-003: 铁掌大师适合安全敏感任务
```

### 读取时机
- 新任务开始时：总裁按任务关键词检索经验
- 检索到的经验作为上下文传给 Worker
- Worker 派发时附带相关经验："上次做类似任务时发现..."

## 检索逻辑

```
新任务到达
  ↓
1. 读取 project_memory.md（全文）
  ↓
2. 提取任务关键词
  ↓
3. 在 topics.md 中匹配主题
  ↓
4. 按 topic 查 experience.jsonl 中的条目
  ↓
5. 汇总检索结果：
   - 项目规则：[相关条目]
   - 经验教训：[相关条目]
   - 最佳实践：[相关条目]
  ↓
6. 作为上下文传给 Worker
```
