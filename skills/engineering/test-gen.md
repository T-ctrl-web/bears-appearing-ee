# Skill: test-gen — 测试生成

## 用途

根据需求自动生成测试用例，由蹦蹦（测试）使用。

## 输入

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| target_files | array | 是 | 被测代码文件路径列表 |
| requirements | string | 是 | 功能需求描述 |
| test_framework | string | 否 | 测试框架，如 jest/pytest |
| coverage_target | number | 否 | 目标覆盖率，默认 80 |

## 测试用例生成策略

### 正常用例
- 每个功能点至少 1 个正常用例
- 验证预期行为和返回值

### 边界用例
- 空值/null/undefined
- 最大值/最小值
- 空字符串/超长字符串
- 数组边界（空数组、单元素、超长）

### 异常用例
- 非法输入类型
- 缺失必填参数
- 超时场景
- 并发冲突

## 输出格式

```
## 测试文件
- `tests/{module}.test.js` — [测试模块说明]

## 测试用例
| 编号 | 类型 | 用例描述 | 输入 | 预期结果 |
|------|------|----------|------|----------|
| T001 | 正常 | {描述} | {输入} | {预期} |
| T002 | 边界 | {描述} | {输入} | {预期} |
| T003 | 异常 | {描述} | {输入} | {预期} |

## 覆盖率预估
- 语句覆盖：~X%
- 分支覆盖：~X%
```

## 调用示例

```
test-gen(
  target_files=["src/auth/login.js"],
  requirements="用户登录：邮箱+密码验证，错误3次锁定",
  test_framework="jest"
)
```
