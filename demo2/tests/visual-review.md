## 色彩分析

### A. 熊二基础样式 — 配色和谐度与对比度

熊二用的是"十年前通用 Flat UI"色板：主色 `#3498db`（Peterriver 蓝）、顶栏 `#2c3e50`（Midnight Blue）、状态色 `#e74c3c` / `#f39c12` / `#27ae60`（Flat 红橙绿）。这套色出自同一时代、同质化严重，与"熊出没集团·松林"品牌零关联——这是和谐度之外的"品牌一致性"问题。

**对比度核算（白底 / `#f5f6f8` 底）：**

| 元素 | 前景色 | 背景色 | 对比度 | AA 正文(4.5) | AA 大字(3.0) |
| --- | --- | --- | --- | --- | --- |
| 主按钮文字 | `#fff` | `#3498db` | 3.13:1 | ✗ | ✓ |
| 主按钮 hover 文字 | `#fff` | `#2980b9` | 4.32:1 | ✗（差一点） | ✓ |
| 主按钮禁用文字 | `#fff` | `#a0cfee` | 1.66:1 | ✗ | ✗ |
| 链接 `.btn-link` | `#3498db` | `#fff` | 3.13:1 | ✗ | ✓ |
| 顶栏标题 | `#fff` | `#2c3e50` | 11.05:1 | ✓ | ✓ |
| 主文本 | `#333` | `#f5f6f8` | ~11.4:1 | ✓ | ✓ |
| 次文本 label | `#555` | `#fff` | 7.83:1 | ✓ | ✓ |
| 任务按钮文字 | `#666` | `#fafafa` | ~5.74:1 | ✓ | ✓ |
| 错误提示 | `#e74c3c` | `#f5f6f8` | 3.56:1 | ✗ | ✓ |
| 空状态提示 | `#bbb` | `#fff` | 1.93:1 | ✗ | ✗ |

**结论：** 顶栏与正文区可读性优秀；但主按钮、链接、错误提示、空状态提示四处正文级文字均不达 AA。错误信息和空状态恰恰是用户最需要看清的内容，反而最糊——这只猫头鹰不接受。

### B. 翠花"松林蜜光"方案 — 配色和谐度与对比度

翠花把色板重构成"松针绿（品牌主） + 蜂蜜蜜（点缀） + 暖调雾白（中性）"三轴，并给三列做了"红警→采蜜→归仓"叙事线，和谐度与品牌感大幅提升，方向正确。但夜视检查发现几处对比度仍踩雷：

| 元素 | 前景色 | 背景色 | 对比度 | AA 正文(4.5) |
| --- | --- | --- | --- | --- |
| 主按钮文字 | `#fff` | `--pine-600 #1f7a5a` | 5.33:1 | ✓ |
| 主按钮 hover | `#fff` | `--pine-700 #176449` | ~7.1:1 | ✓ |
| 登录标题 h2 | `--pine-900 #0b3d2e` | `#fff` | ~13:1 | ✓ |
| 次文本 label | `--text-2 #5a6b62` | `#fff` | 5.67:1 | ✓ |
| 任务按钮文字 | `--text-2 #5a6b62` | `#fff` | 5.67:1 | ✓ |
| 顶栏文字 | `#fff` | `--pine-700` 渐变 | ~7.1:1 | ✓ |
| 登出按钮文字 | `#fff` | pine-700 + 8% 白 | ~6.5:1 | ✓ |
| **蜜色链接** | `--honey-600 #d97f06` | `#fff` | **3.03:1** | ✗ |
| **计数徽标（待办）** | `--todo-500 #e0584c` | `--todo-50 #fdeceb` | **3.56:1** | ✗ |
| **计数徽标（完成）** | `--done-500 #2f9e6d` | `--done-50 #e6f4ee` | **3.18:1** | ✗ |
| **占位/空状态文字** | `--text-3 #9aaaa0` | `#fff` | **2.41:1** | ✗ |

**结论：** 翠花方案把熊二的 4 处不达标修好了 3 处（主按钮、主文本体系、顶栏），但**新引入了 3 处不达标**（蜜色链接、计数徽标、`--text-3` 信息文字）。蜜色和浅底徽标视觉上确实好看，但好看不能以可读性为代价。建议：蜜色限定为图标/装饰色，文字链接用更深的 `--honey-700`；徽标改"白字实色底"；`--text-3` 仅用于纯占位符，信息文字上移到 `--text-2`。

### C. 色盲友好性

熊二的三列状态色（红 `#e74c3c` / 橙 `#f39c12` / 绿 `#27ae60`）在红绿色盲（最常见的 protanopia / deuteranopia）下，红与绿明度接近、易混淆，且仅靠 `border-bottom` 单一通道编码，色盲用户难以区分待办与完成。翠花方案 4.4 增加"圆点 + 计数徽标 + 顶部色条"是正确补救（多通道冗余），但徽标本身的对比度问题见 #10。建议再补一层形状图标（▢ 待办 / ◐ 进行中 / ✓ 完成），形成"颜色+形状+数字+文字"四重冗余，彻底脱离"仅靠颜色"。

## 审查结论

**视觉质量评分：熊二基础样式 4.5 / 10；翠花方案落地后（含本报告 P0–P1 修复）可达 8.5 / 10。**

熊二的基础样式功能态完整、布局可用，但作为"集团看板"的视觉交付物不合格：通用蓝与品牌无关、主按钮/链接/错误提示/空状态四处正文级文字不达 AA、所有按钮无 focus 态、圆角与间距无体系、状态色仅靠颜色编码对色盲不友好。它是一个"能用但不好看也不够友好"的底子。

翠花的"松林蜜光"方案在品牌化、令牌化、留白、微动效、多通道状态编码上方向正确，能把底子抬到优秀线；但需先堵住它自己引入的 3 处对比度缺口（蜜色链接 / 浅底计数徽标 / `--text-3` 信息文字），并补上它和熊二共同漏掉的按钮 `:focus-visible`——这只猫头鹰夜里盯着的，恰恰就是这几像素、这 0.5:1 的差距。
