## 三、发现的问题列表

### 问题 #1 ｜ emoji 字段未经 HTML 转义（安全一致性）

| 项 | 内容 |
|----|------|
| 严重度 | **P1 严重** |
| 位置 | `roster.html:346` |
| 现象 | 渲染模板 `<span class="card__avatar">${r.emoji}</span>` 直接输出 `r.emoji`，未调用 `esc()`。同模板内 name/title/animal/duty/color/tier 六字段均经 `esc()`，唯独 emoji 遗漏。 |
| 判断 | 代码注释（:322）明写「HTML 转义，防注入」，却自留口子。当前 ROLES 为内部可信数据，实际风险不暴露；但这是"声称有防护、实际有漏洞"的质控硬伤，本国王不能装看不见。 |
| 建议 | 改为 `${esc(r.emoji)}`，一行修复。快快快！ |

### 问题 #2 ｜ 色条注释与实现不符（应为左侧，实为顶部）

| 项 | 内容 |
|----|------|
| 严重度 | **P2 中度** |
| 位置 | `roster.html:139-145` |
| 现象 | 注释（:139）写「左侧色条：角色专属色」，实现（:141-142）却是 `height:4px; width:100%`——卡片**顶部横条**，非左侧竖条。 |
| 判断 | 原始任务要求未规定色条方向，故不构成"任务偏离"；但注释与实现自相矛盾，会误导维护者。本国王据此降一级定为 P2（蹦蹦的测试报告因对照内部 spec 定为 P1，本国王以原始任务为准）。 |
| 建议 | 二选一：① 改 CSS 为左侧竖条（`width:4px;height:100%` + `.card` 改 flex 布局）；② 或把注释改为「顶部色条」。注释与实现统一即可。 |

### 问题 #3 ｜ tier 字段无效值被静默丢弃（健壮性）

| 项 | 内容 |
|----|------|
| 严重度 | **P2 中度** |
| 位置 | `roster.html:334` |
| 现象 | `if(buckets[r.tier])` 对无效 tier 静默跳过，角色消失无任何提示。 |
| 判断 | 数据录入错误时"角色去哪了"极难排查。MVP 阶段数据可控，但改一行加个 warn 成本几乎为零，性价比高。 |
| 建议 | 加 `else { console.warn('未知 tier:', r.tier, r.name); }`。 |

### 问题 #4 ｜ font-weight 使用非标准值 650

| 项 | 内容 |
|----|------|
| 严重度 | **P3 轻度** |
| 位置 | `roster.html:101` |
| 现象 | `font-weight:650`。标准值应为整百（100-900）。650 虽语法合法（Fonts Level 4 允许 1-1000），但大多数字体只提供 400/700，会被映射到最近值，跨字体表现不一致。 |
| 建议 | 改为 `700`。 |

### 问题 #5 ｜ color-mix() 在旧浏览器失效

| 项 | 内容 |
|----|------|
| 严重度 | **P3 轻度** |
| 位置 | `roster.html:137,194,195,196` |
| 现象 | `color-mix(in srgb, ...)` 需 Chrome 111+ / Safari 16.2+ / Firefox 113+。旧浏览器上 hover 边框色、层级标签底色将失效（标签可能无背景）。 |
| 判断 | 现代浏览器正常，属渐进增强问题，MVP 阶段可接受。 |
| 建议 | 为 `.card__tag--*` 补一条 `rgba()` fallback 背景色，再写 color-mix 增强版。 |

### 问题 #6 ｜ 萝卜头 emoji 与动物类型不符

| 项 | 内容 |
|----|------|
| 严重度 | **P3 轻度** |
| 位置 | `roster.html:314` |
| 现象 | `animal:'鼹鼠'`，但 `emoji:'🐭'`（老鼠 / mouse）。emoji 字典无独立"鼹鼠"表情，语义不准。 |
| 建议 | 可接受现状（emoji 字典限制），或在卡片加文字辅助说明。 |

### 问题 #7 ｜ 熊大与熊二 emoji 相同，视觉无法区分

| 项 | 内容 |
|----|------|
| 严重度 | **P3 轻度** |
| 位置 | `roster.html:306,310` |
| 现象 | 熊大、熊二 `emoji` 均为 `🐻`，头像层无法区分两头棕熊（animal 同为"棕熊"是合理设定）。 |
| 建议 | 可接受（emoji 字典中熊表情单一），或用不同 emoji / 文字首字占位区分。 |

### 补充观察 ｜ 注释表述不够精确（非 Bug）

| 项 | 内容 |
|----|------|
| 严重度 | **P3 轻度（文档）** |
| 位置 | `roster.html:118` |
| 现象 | 注释「无媒体查询即可自适应」与下方 :234 存在 media query 略有矛盾。语义可解为"grid 本身自适应，media query 仅窄屏微调"，但表述不够精确。 |
