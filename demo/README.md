## 1. 页面简介

一张单文件、零依赖的深色花名册页面，按 Leader / Worker / Verifier 三层分组展示熊出没集团 7 个 MVP 角色卡片。

## 2. 功能说明

- 三层分组展示：领导层 / 执行层 / 验证层，各带计数角标。
- 数据驱动渲染：改 `ROLES` 数组即改页面，无需碰 HTML。
- 角色专属色：每张卡片左侧色条、姓名、悬停光晕由 `color` 字段驱动。
- 响应式网格：CSS Grid `auto-fill + minmax(260px,1fr)`，桌面多列、移动单列自适应。
- 微交互：卡片悬停上浮 + 色条发光；`prefers-reduced-motion` 下自动关闭动效。
- 无障碍：语义化 `article/dl/header`，emoji 作头像零图片依赖。

## 3. 如何使用

双击 `roster.html` 用任意浏览器打开即可，无需服务器、无需联网、无需安装任何依赖。文件就在本目录（`demo/roster.html`）。

## 5. 如何添加新角色

打开 `roster.html`，找到 `<script>` 里的 `ROLES` 数组，照葫芦画瓢加一项即可：

```js
{ name:'新角色名', title:'职位', animal:'物种', emoji:'🐾',
  duty:'一句话职责', tier:'worker', color:'#RRGGBB' }
```

`tier` 取 `leader` / `worker` / `verifier` 三选一，卡片自动归组、计数自动更新，零 CSS 改动。

## 6. 技术栈

原生 HTML + CSS（变量 + Grid，内联 `<style>`）+ 原生 JS（数据数组 + 渲染函数，内联 `<script>`）。单文件、零外部依赖、可离线运行。
